# SCP Transfer Guide

Send the project to the notebook at 192.168.0.100 using the password method.

## 1. Package the project locally

```bash
cd /Users/jungwoosong/Developer/thermal/weather
tar --exclude='venv' --exclude='__pycache__' --exclude='*.pyc' --exclude='.DS_Store' --exclude='weather-receipt-printer.tar.gz' -czf weather-receipt-printer.tar.gz .
```

## 2. Transfer with SCP

Run in a local terminal. Enter the notebook password when prompted.

```bash
scp /Users/jungwoosong/Developer/thermal/weather/weather-receipt-printer.tar.gz jungwoos@192.168.0.100:~/weather-receipt-printer.tar.gz
```

## 3. Extract on the notebook

```bash
ssh jungwoos@192.168.0.100
rm -rf ~/weather-receipt-printer-old
mv ~/weather-receipt-printer ~/weather-receipt-printer-old
mkdir -p ~/weather-receipt-printer
tar -xzf ~/weather-receipt-printer.tar.gz -C ~/weather-receipt-printer
cd ~/weather-receipt-printer
```

## 4. Set up the virtual environment

```bash
cd ~/weather-receipt-printer
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 main.py --dry-run
```

## 5. Test the physical printer

```bash
cd ~/weather-receipt-printer
source .venv/bin/activate
python3 main.py
```

## 6. Register cron for daily 07:00 print

```bash
crontab -e
```

Add this line:

```cron
0 7 * * * /home/jungwoos/weather-receipt-printer/.venv/bin/python /home/jungwoos/weather-receipt-printer/main.py >> /home/jungwoos/weather-receipt-printer/run.log 2>&1
```

Verify with:

```bash
crontab -l
```

## USB Permission Fix

If printing fails with permission denied, run this on the notebook.
Replace `04b8` and `0202` with the actual vendor/product id from `lsusb`.

```bash
lsusb

sudo tee /etc/udev/rules.d/99-thermal-printer.rules <<'EOF'
SUBSYSTEM=="usb", ATTR{idVendor}=="04b8", ATTR{idProduct}=="0202", MODE="0666", GROUP="lp"
EOF

sudo udevadm control --reload-rules
sudo udevadm trigger
```

Then unplug and replug the printer, or reboot the notebook.
